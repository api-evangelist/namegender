# NameGender

> NameGender is a name-to-gender API and managed spreadsheet service. It returns a statistical association together with probability, evidence count, confidence, country and source, and it can return unknown when evidence is insufficient.

Name-based inference does not identify an individual's gender. Preserve unknown results and evidence fields. Do not use inferred gender for employment, medical, financial, insurance, legal or eligibility decisions.

The public website and the resources below are in English unless a locale-specific URL is provided. The REST API is versioned under /api/v1, uses JSON, and takes the API key in an Authorization: Bearer or X-Api-Key header. Purchased credits remain available until used.

## Methods and comparisons

- [NameGender Research](https://namegender.com/research): Index of measured reports, methods and disclosed limitations.
- [Gender Prediction API Benchmark 2026](https://namegender.com/research/gender-api-benchmark-2026): Results for 4,610 labelled names across 25 countries, split by country and writing system.
- [Benchmark methodology](https://namegender.com/research/methodology): Coverage, accuracy and end-to-end definitions, holdout rules, reproducible commands and limitations.
- [Names that change gender by country](https://namegender.com/research/names-that-change-gender-by-country): Open CC BY 4.0 dataset from official name counts in twelve national registers across ten countries (479 names flip); names such as Jean, Andrea, Kim and Toni that are mostly girls in one country and mostly boys in another. CSV: https://namegender.com/datasets/names-gender-by-country.csv
- [How accurate is gender prediction from a name?](https://namegender.com/blog/how-accurate-is-gender-prediction-from-a-name): Coverage, accuracy when answered and end-to-end results by writing system, and how well the probability field is calibrated.
- [65 names that change gender by country](https://namegender.com/blog/names-that-change-gender-by-country): Names recorded as mostly male in one country and mostly female in another, from counted birth registrations.
- [How to compare gender APIs](https://namegender.com/blog/how-to-compare-gender-apis): Reproducible evaluation using coverage, accuracy when answered and end-to-end accuracy.
- [Best gender APIs in 2026](https://namegender.com/blog/best-gender-apis): Date-stamped shortlist and buyer's test.
- [Genderize alternatives](https://namegender.com/blog/genderize-alternatives): Migration criteria and shadow-testing method.
- [Gender API comparison](https://namegender.com/blog/gender-api-comparison): Comparison worksheet for evidence, country handling, throughput, billing and privacy.
- [Coverage by writing system](https://namegender.com/blog/coverage-by-script): Published fixture results and known gaps by script.
- [Probability and evidence fields](https://namegender.com/blog/probability-confidence-and-sample-size): How to interpret probability, confidence and sample_size.
